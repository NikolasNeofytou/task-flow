### Βήμα 4: Χρήση

#### Δημιουργία Task
1. Πατήστε το "+" στην κεντρική οθόνη
2. Συμπληρώστε τίτλο και περιγραφή  
3. Επιλέξτε deadline
4. Πατήστε "Create Task"

#### Πρόσκληση Ομάδας
1. Μπείτε σε project → "Invite Members"
2. Δείξτε το QR code σε άλλη συσκευή

#### Αποστολή Μηνυμάτων  
1. Chat tab → Επιλέξτε project
2. Γράψτε μήνυμα ή πατήστε μικρόφωνο για φωνή
3. Πατήστε "Send"
